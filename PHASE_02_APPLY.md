# Applying the Phase 02 implementation

1. Make a backup or commit your current `frontend-phase-02` working tree.
2. Extract this ZIP into the repository root, preserving the folder structure and allowing the included source/documentation files to overwrite their matching files.
3. Do not replace `package.json` or `package-lock.json`; neither file is included in this ZIP.
4. Install the manual development dependencies in `docs/phase-02-manual-dependencies.md`.
5. Run the tests, type check, and lint commands in the dependency guide.
6. Open the Expo app and review the design-system preview on small and large Android/iOS layouts.

This archive intentionally excludes `.env`, `.git`, `.expo`, `node_modules`, `package.json`, and `package-lock.json`.
