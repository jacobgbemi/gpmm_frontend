- `product-requirements.md` — functional and non-functional requirements.

- `frontend-architecture.md` — mobile frontend structure and conventions.

- `api-specification.md` — proposed REST API contract.

- `architecture-decisions.md` — architecture decision records.

## Delivery and quality

## Document status
These documents describe the approved project direction and proposed implementation contracts. They are not evidence that the software, endpoints, integrations, or infrastructure have already been implemented. Where a provider or operational detail is marked as proposed or to be selected, confirm it before implementation.
